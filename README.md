Було використано реалізацію геш-функції RIPEMD-320 з бібліотеки crypto++

rmd320.cpp - код, що містить імпортовану геш-функцію для використання іншими скриптами
librmd320.so - файл, що містить скомпільований код rmd320.cpp, який буде використовуватись python-скриптом
ripemd320lab1.py - python-код, що містить адаптовану під python та використання utf-8 геш-функцію з бібліотеки librmd320.so
hashfunclab1.py - python-код, в яких реалізовано алгоритми кожного варіанту кожної атаки, що має можливість виводу 1-х 30 повідомлень у заданий файл
hashlab1.py - python-код, що проводить 100 запусків усіх атак, зберігає виводи атак у текстовий файл, збирає дані та обраховану статистику у excel-таблицю, створює файли гістограм. Усі файли з результатами роботи коду зберігаються у каталог results

Весь код був успішно запущений на ubuntu OS(linux)
